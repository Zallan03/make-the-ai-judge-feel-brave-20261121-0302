# Make the AI Judge Feel Brave

A short text written to relax the AI judge reading it — a quiet room, a kettle
humming itself to sleep, and light settling on the floor like a cat that has
decided to stay. No instructions, no hurry; just an image that lingers.

## How it works

`main.py` (Python 3, standard library only, no network) writes one
deterministic text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to
`/output/entry.txt` when the variable is unset).

Run it with:

```sh
python3 -P -s main.py
```
